# Photos to add

Drop your own photos into this `images/` folder using the **exact file names**
below. The website already points to these names, so nothing else needs to
change — the placeholder blocks on the site disappear the moment a matching
file appears here.

Tips for jewellery photos: shoot on a plain background (a black or dark green
cloth works well), use soft daylight or a ring light to avoid glare on the
metal, and keep the piece in sharp focus filling most of the frame.
